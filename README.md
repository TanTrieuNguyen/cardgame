# 🎴 Card Game Platform (Made By Tan Trieu Nguyen)

Nền tảng Web Game bài trực tuyến đa trò chơi (Multi-game Card Platform) bao gồm **Blackjack (Xì Dách)** và **UNO**, được xây dựng bằng **Node.js**, **Express**, và **Socket.io**.

![Card Game Banner](https://img.shields.io/badge/Status-Active-brightgreen) ![Author](https://img.shields.io/badge/Author-Tan%20Trieu%20Nguyen-blue)

---

## 🌟 Trải Nghiệm & Trò Chơi

1. **🎬 Màn Hình Đen Mở Đầu (Splash Screen)**:  
   Mở web lên hiện màn hình đen mượt mà với hiệu ứng chữ phát sáng **`Made By Tan Trieu Nguyen`**.
2. **🎴 Game Selector (Trung Tâm Trò Chơi)**:  
   Lựa chọn giữa 2 tựa game bài đỉnh cao:
   - 🃏 **Blackjack (Xì Dách)**: Hỗ trợ 1-6 người chơi. Có chế độ chơi 1 mình (Solo vs Dealer) hoặc tạo phòng 6 người.
   - 🎴 **UNO Multiplayer**: Hỗ trợ 2-8 người chơi trực tuyến (Không có solo).
3. **🎁 Cứu Trợ 200 Phỉnh**:  
   Khi hết sạch tiền, hiển thị Popup thông báo với nút **`🎁 Nhận 200 và làm lại từ đầu`**.
4. **🔥 Đặt Cược Thông Minh**:  
   Nút **ALL IN**, **½ HALF**, tự động khóa nút cược vượt quá số dư và nút **➖ Hủy cược**.
